## 📌 About the Internship
This repository houses all my completed projects for the **Oasis Infobyte Student Internship Program (OIBSIP)** under the **Python Programming** domain. Each project is designed to demonstrate problem-solving capabilities, input validation logic, control flow structuring, and third-party REST API integration.

## 📂 Project Showcase

| Task # | Project Name | Directory Path | Core Technologies | Description |
| :---: | :--- | :--- | :--- | :--- |
| **01** | **BMI Calculator** | [`Python-Task1-BMICalculator/`](./Python-Task1-BMICalculator/) | Python, Math Logic | Calculates Body Mass Index with WHO health categorizations and safety validation. |
| **02** | **Password Generator** | [`Python-Task2-PasswordGenerator/`](./Python-Task2-PasswordGenerator/) | Python (`random`, `string`) | Generates customizable, high-security passwords based on user complexity preferences. |
